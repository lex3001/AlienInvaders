# Alien Invaders

This repository is the home for the **Alien Invaders** project: a modernized, updated version of the original 1998–1999 game. The modernization effort is planned, but **the only code currently present is the original VB6 version from 1999**, located in the `vb6/` folder.

## What’s Here Today

- **Original VB6 source code (1999)** — complete project, assets, and historical release notes.
- **Comprehensive documentation** — detailed technical and gameplay docs under `vb6/docs/`.

## Start Here

- Original VB6 project overview: [vb6/README.md](vb6/README.md)
- Documentation index: [vb6/docs/README.md](vb6/docs/README.md)

## Repository Layout

- `vb6/` — Original Visual Basic 6 code and assets (1999)
- `vb6/docs/` — In-depth technical documentation for the original game

## Future Work

A refreshed, modern implementation is intended for this repository. Until then, the VB6 version is the authoritative source for game behavior, assets, and reference documentation.
